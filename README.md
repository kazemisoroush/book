# Audiobook Generator

A Python CLI that converts text books into structured, multi-voice audiobook data with AI-powered dialogue beatation and character tracking.

## What It Does

1. Downloads the HTML format text book from Project Gutenberg website.
2. Deterministicly parse metadata (title, author, release date) and extracts chapters and sections
3. Uses AI to understand context and extract deeper meaning from book.
4. Uses audio providers to convert beats to audio pieces.
5. Composes the pieces together.
